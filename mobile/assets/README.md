# Mobile App Assets

- `logo.png` — source brand logo (1024×1024, transparent background), used directly
  in the login/register screens.
- `icon.png` — 1024×1024 app icon (iOS App Store + Android), generated by
  compositing `logo.png` over the app's dark background (#07090f).
- `adaptive-icon.png` — 1024×1024 foreground for Android's adaptive icon,
  `logo.png` scaled to ~62% and centered to stay within the launcher mask's
  safe zone, kept transparent (background color comes from app.json).
- `splash.png` — 1284×2778 splash screen, `logo.png` centered on #07090f.

Regenerate icon.png/adaptive-icon.png/splash.png from a new logo.png with
Pillow (see git history for the exact script used).
